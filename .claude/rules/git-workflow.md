# Git Workflow

- Branch names: `feat/`, `fix/`, `chore/`, `docs/`, `refactor/`, `test/` + short description.
- A commit message is one Conventional Commits subject line. No body and no trailers,
  including any session or attribution line.
- A pull request body carries no session link or attribution line either.
- Do not run `bd dolt push` unless asked.
